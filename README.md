# UK Solar Calculators

A small open-source collection of lightweight solar calculators for UK homeowners.

## Included tools

- **Solar Payback Calculator**
- **Solar Panel Number Calculator**
- **Solar Battery Size Calculator**

The tools are designed for quick educational estimates rather than professional system design.

## Live demo

After enabling GitHub Pages:

```text
https://YOUR-GITHUB-USERNAME.github.io/uk-solar-calculators
```

## Solar Payback Calculator

Estimate how long a solar panel system may take to recover its upfront cost.

**Full Green Energy Today calculator:**  
https://newgreenenergytoday.blogspot.com/p/solar-calculator.html

## Solar Panel Number Calculator

Estimate how many solar panels may be required from annual electricity consumption, panel wattage and expected solar yield.

**Detailed guide:**  
https://newgreenenergytoday.blogspot.com/2026/09/how-many-solar-panels-do-i-need-uk.html

## Solar Battery Size Calculator

Estimate a possible battery capacity based on daily consumption, evening use and usable battery capacity.

**Detailed guide:**  
https://newgreenenergytoday.blogspot.com/2026/09/what-size-solar-battery-do-i-need-uk.html

## Run locally

No build tools are required. Open `index.html` in a browser.

## Enable GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Open **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main`.
6. Select `/ (root)`.
7. Click **Save**.
